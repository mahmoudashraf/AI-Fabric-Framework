# LoomAI Landing Pages — Content and Structure

Status: planning document (2026-05-06)

No fluff. No startup theater. Product-first pages that show what it does, prove it works, and let people act.

# loomai.pro

## The Whole Page in One Sentence

Show the products. Show them working. Let people try them.

---

## Structure

```
NAV (minimal)
PRODUCT WALL (every product, live)
LOOM COMPANION DEEP DIVE (demo + steps)
PRICING (direct, no comparison theater)
FOR DEVELOPERS (one block)
FOOTER (links only)
```

That's it. Five sections. No "about us," no "our mission," no testimonials from people who don't exist yet.

# Design Notes (Both Pages)

## Dark theme

```
Background:     #0B0F1A
Surface:        #141B2D
Border:         #2A3352
Accent:         #6C8EEF
Text:           #E2E8F0
Secondary:      #94A3B8
```

## Typography

```
Font:           Inter
Headlines:      24-32px, weight 600
Body:           16px, weight 400
Mono (prices):  JetBrains Mono
```

## Page weight

Target: under 500KB total including images. Fast load. No framework bloat.

If the demo embed is heavy, lazy-load it below the fold.

## Mobile

Both pages are single-column on mobile. No hamburger menu (there are only 3-4 links — show them all or hide the nav entirely on mobile and let the page scroll).

## Build

Static HTML + Tailwind. No React. No Next.js. No build step if possible. These are landing pages, not applications.

If forms need a backend: Formspree or simple API endpoint on api.loomai.pro.
