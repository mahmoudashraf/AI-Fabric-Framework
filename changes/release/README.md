# Release Change Plans

This folder contains **release-focused** change-plan documents (beta → GA), with an emphasis on:
- A direct, testable release path
- Clear **Community vs Enterprise** separation (monorepo)
- Packaging, CI, and licensing mechanics

## Documents
- `BETA_RELEASE_SCOPE_AND_GATES.md` — what “beta” means + go/no-go gates
- `MONOREPO_COMMUNITY_ENTERPRISE_SEPARATION_CHANGE_PLAN.md` — recommended monorepo split + build boundaries
- `ARTIFACT_COORDINATES_AND_NAMING_FIXES_CHANGE_PLAN.md` — fix Maven coordinates/artifact naming inconsistencies before publishing
- `V0_RELEASE_PLAN_CHAT_CAPABILITIES_BASELINE.md` — v0 golden path using the chat demo app
- `V0_RELEASE_CHECKLIST.md` — actionable v0 release checklist
- `SHIPPING_PROCESS_AND_DISTRIBUTION_OPTIONS.md` — what we ship + how we ship it
- `DEPLOYMENT_OPTIONS_AND_VECTOR_DB_SUPPORT.md` — deployment models and vector DB options
- `OPTION_D2_SELF_HOSTED_RUNTIME_JAR_PLAN.md` — plan to ship a runnable runtime JAR (Option D2)
