- Packaging, CI, and licensing mechanics

- `MONOREPO_COMMUNITY_ENTERPRISE_SEPARATION_CHANGE_PLAN.md` — recommended monorepo split + build boundaries
- `ARTIFACT_COORDINATES_AND_NAMING_FIXES_CHANGE_PLAN.md` — fix Maven coordinates/artifact naming inconsistencies before publishing
- `V0_RELEASE_PLAN_CHAT_CAPABILITIES_BASELINE.md` — v0 golden path using the chat demo app
