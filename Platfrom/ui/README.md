# Platform UI

This is the initial control-plane UI scaffold.

Chosen V1 stack:

- React
- TypeScript
- Vite
- Material UI
- @tanstack/react-query
- react-hook-form
- zod

Initial screens are placeholders for the phased implementation plan:

- Deployments
- Actions
- Knowledge
- Providers
- Security
- Verification
- Revisions
- Diagnostics

Local API base URL:

- `VITE_PLATFORM_API_BASE_URL=http://localhost:8088`
