# Capability Preview Icons

These small, self-hosted assets illustrate the providers already supported by
the Platform configuration editor. They are not installed service indicators.
Names always accompany icons. No remote icon CDN or runtime dependency is used.

- OpenAI, Claude, Gemini, Azure and Cohere: [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/ea434b96e75813517b377825e01c0df61dee8836/packages/static-svg/icons),
  revision `ea434b96e75813517b377825e01c0df61dee8836`, MIT.
  See `LICENSE-lobe-icons.txt`.
- Qdrant, Milvus, Apache Lucene and ONNX: [Simple Icons](https://github.com/simple-icons/simple-icons/tree/46d3327aee33fbe00ebfbb5da1543853a295c297/icons),
  revision `46d3327aee33fbe00ebfbb5da1543853a295c297`, CC0.
  See `LICENSE-simple-icons.txt`.

icons from the existing library, not imitations of those providers' trademarks.
