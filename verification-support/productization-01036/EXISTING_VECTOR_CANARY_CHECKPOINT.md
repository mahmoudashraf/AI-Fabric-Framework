## Important Limits

The pinned Milvus adapter does not select an arbitrary database through its
SDK connection. Accept only `default` and isolate using the frozen unique
collection prefix; do not claim database-name isolation. Non-default requests
are explicitly rejected. The real cluster's default alias must be verified
with its serving credentials before data writes.

This is one exclusive synthetic staging allocation, not evidence that Free
provides collection-level tenant ACLs. Application-owned collection prefixes
and metadata isolation do not turn an administrator serving credential into a
provider-enforced tenant-limited credential. Production multi-customer storage
and promotion need a separately reviewed provider/credential boundary.

Existing target-index retirement normally clears that target's collections.
For a retained external binding this must be blocked before any clear call.
Until a fully evidenced retained-index completion contract exists, report the
explicit retention blocker rather than invented empty counts, reclaimed index
capacity, or successful full retirement. Keep the external data intact.
