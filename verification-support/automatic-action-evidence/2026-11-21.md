## Implemented

- Missing `llmFacts` and explicit `AUTOMATIC` prepare bounded nested JSON from
  successful `ActionPayload`, not execution context or HTTP transport material.
- Existing explicit projections remain selected. Empty `SELECTED_FIELDS` does
  not fall back. Mode switching preserves inactive rules.
- Recursive known structured credential fields and declared sensitive parameter
  field names are excluded. Producers still own their approved output contract;
  this is not classification of arbitrary confidential fields or prose secrets.
- Preparation limits: six nesting levels, ten list items, 32 visited map entries,
  256 nodes, 12,000 serialized data characters and 2,000 characters per text leaf.
  Truncation remains visible; existing orchestration budgets still apply.
- Successful write receipts retain actual facts; failed payload data is not
  automatically forwarded. No hidden generation or replay was introduced.
- Assistant resource guidance describes Automatic and exact advanced projection
  paths. It no longer requires a field projection merely for action evidence.
- The older Shopify defaults helper preserves explicit evidence modes and empty
  projections instead of replacing an operator's exposure choice. Existing
  curated projections are retained; no Shopify product rollout is claimed.
- No new page, parallel editor or backend database migration.
