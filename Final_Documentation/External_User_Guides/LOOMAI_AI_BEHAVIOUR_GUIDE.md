# Configure Your AI Behaviour

Open your Kit's Smart Brain and choose **AI behaviour**. Customers and authorized
LoomAI staff use the same editor and release process. Every Engage channel
connected to that Brain uses its applied configuration.

## Choose Your Profiles

- **Conversation tone:** Professional, Warm, Consultative or Technical.
- **Answer breadth:** Grounded uses approved knowledge and live facts. Advisory
  adds clearly identified general advice. Exploratory also permits broader
  alternatives and brainstorming without claiming they are your offerings.
- **Answer length:** Brief, Balanced or Detailed.
- **Next steps:** Off or Contextual. Contextual permits up to two useful
  same-turn suggestions; no suggestion is also a valid result. Clicking one
  submits a normal query and does not authorize an action.

All profiles preserve authorization, required action fields, trusted targets,
confirmation and budgets. Business prices, stock, policies, commitments and
action outcomes still need approved evidence. No profile searches the internet
or changes the provider's sampling temperature.

## Review And Publish

1. Select profiles, then choose **Review changes**.
2. Inspect the before/after instructions. **Cancel** leaves your editor alone.
   **Apply to editor** changes only the browser buffer.
3. Choose **Save prompt draft**. Reopening the editor retains those choices.
4. Use the existing validation, publish and apply flow to change a live Brain.

**Choose defaults** is an explicit editor operation, not an immediate live reset.
Templates provide initial settings; they do not lock future changes or update
existing deployments automatically.

## Advanced And Preview

Expand **Advanced profile instructions** to customize a profile. Editing its
instructions makes it **Custom**. Reapplying a named preset restores only that
profile. Separate customer base prompts and unrelated configuration remain
preserved; review any warning about conflicting custom instructions.

These instructions guide the model; they do not guarantee an exact length,
sentence ending or identical response on every turn. Model text is not trimmed
with phrase filters to make it appear compliant.

Use the named **Off** preset to disable optional next steps. Custom next-step
instructions guide the model; they are not a replacement for that explicit
runtime policy.

**Try a conversation** can compare the applied configuration with an editor-only
prompt preview. The preview overrides only the seven managed prompt strings.
It does not simulate new provider settings, runtime recommendation controls or
new infrastructure. In particular, a currently applied Off policy can suppress
Contextual suggestions until the new configuration is published and applied.

Advanced session hot apply and prompt revisions retain their existing scope.
They are not a replacement for publishing a production release.
