# Landing Page Build Prompt for AI Fabric Framework

## 🎯 Project Brief

Create a stunning, conversion-focused landing page for **AI Fabric Framework** - an open-source Spring Boot framework that makes adding AI capabilities to applications as simple as adding an annotation.

---

## 🎨 Design Philosophy

**Tone**: Professional yet approachable, developer-focused, problem-solving  
**Vibe**: Modern SaaS landing page meets developer documentation  
**Colors**: Deep blues/purples for tech feel, bright accent colors for CTAs  
**Feel**: Clean, spacious, highly readable, with code examples that pop

```
    public class Product {
        @Id private UUID id;
        private String name;
        private String description;

    ──────────────────────────────────────
    @Autowired
    private AISearchService searchService;
```

## 💻 Technical Implementation

### **Tech Stack Recommendation**
```
Frontend: Next.js 14 + TypeScript + Tailwind CSS
Styling: Tailwind CSS + Framer Motion (animations)
Forms: React Hook Form + Zod (validation)
Icons: Lucide React or Heroicons
Syntax Highlighting: Prism.js or Shiki
Animations: Framer Motion
Deployment: Vercel or Netlify
```

**Form Submission Endpoint**: `POST /api/register-interest`

**Request Payload**:
```json
{
  "email": "developer@example.com",
  "modules": [
    "ai-core",
    "behavior-analytics",

    "web-module",
    "onnx-provider"
  ],
  "timestamp": "2024-01-15T10:30:00Z",
```

**Response (Success)**:
```json
{
  "success": true,
  "message": "Thank you! We'll keep you updated.",
```


## 🎨 Design Guidelines

### **Color Palette**
```
Primary: #2563eb (Blue 600)
Secondary: #7c3aed (Purple 600)
Accent: #10b981 (Green 500)
Background: #ffffff (White)
Surface: #f9fafb (Gray 50)
Text: #111827 (Gray 900)
Text Secondary: #6b7280 (Gray 500)
Border: #e5e7eb (Gray 200)
Code Background: #1e293b (Slate 800)
```

### **Typography**
```
Headings: Inter or Manrope (Bold, 600-800)
Body: Inter or System UI (Regular, 400)
Code: JetBrains Mono or Fira Code (400)

Heading Sizes:
- H1 (Hero): 3.5rem (56px), line-height 1.1
- H2 (Section): 2.5rem (40px), line-height 1.2
- H3 (Subsection): 1.75rem (28px), line-height 1.3
- Body: 1.125rem (18px), line-height 1.7
```

### **Spacing System**
```
Use 8px base unit:
xs: 8px
sm: 16px
md: 24px
lg: 32px
xl: 48px
2xl: 64px
3xl: 96px
```

### **Animation Guidelines**
- Page load: Fade in + slide up sections (stagger 100ms)
- Code typing: Typewriter effect at 50ms per character
- Hover effects: Scale 1.02, duration 200ms
- Button press: Scale 0.98, duration 100ms
- Form submission: Button spinner, disable form
- Success: Checkmark animation + fade to success message

## 📱 Responsive Design

### **Breakpoints**
```
Mobile: 0-640px
Tablet: 641px-1024px
Desktop: 1025px+

Mobile:
- Stack all layouts vertically
- Single column module grid
- Larger touch targets (48px min)
- Simplified navigation (hamburger menu)

Tablet:
- 2-column module grid
- Maintain spacing hierarchy
- Readable code blocks

Desktop:
- 3-column module grid
- Full navigation visible
- Wider code blocks
- Sticky CTA in header
```
