## General Image Guidelines

### Technical Specifications
- **Resolution:** 1920x1080 (16:9) minimum
- **Format:** PNG or JPG
- **File Size:** Under 2MB for web
- **Color Profile:** sRGB

### Style Consistency
- Modern, clean, professional
- Tech-forward aesthetic
- Blue/green color schemes (trust, success)
- Minimal, focused compositions
- High contrast for readability

### Text Overlay Considerations
- Leave space for Medium title overlay
- Avoid text-heavy areas in center
- Ensure readability with title text

### Optimization Tips
- Use image compression tools (TinyPNG, ImageOptim)
- Test on different screen sizes
- Ensure accessibility (alt text descriptions provided)

- Start with "Option 1" (recommended) for each

- Consider stock photo alternatives for simpler needs
